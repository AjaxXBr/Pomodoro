# 🍅 Pomodoro Timer

Aplicação **Pomodoro** desenvolvida com **HTML, CSS e JavaScript puro**, focada em gerenciamento de tempo, produtividade e concentração durante tarefas de estudo ou trabalho.  

🔗 **Acesse o projeto online:**  
👉 https://ajaxxbr.github.io/Pomodoro/

---

## 🚀 Funcionalidades

✅ Contador de tempo no formato `HH:MM:SS`  
▶️ Iniciar o cronômetro  
⏸️ Pausar o tempo  
🔄 Zerar o contador  
🎯 Ideal para técnica Pomodoro (25 minutos de foco)

---

## 🛠️ Tecnologias Utilizadas

- 🧱 **HTML5** — estrutura da aplicação  
- 🎨 **CSS3** — estilização e layout  
- ⚙️ **JavaScript (Vanilla JS)** — lógica do cronômetro e eventos
